## Implemented Outcomes
- OAuth clients persist registrar owner, tenant, and attenuated scopes; legacy BASE-shaped records require authenticated secret proof and registrar authority before one-time upgrade.
- Legacy authority upgrade uses a fresh SQLite read and `BEGIN IMMEDIATE` compare-and-set. A four-process shared-database regression proves exactly one winner and fresh-process reload/authentication of the persisted winner and binding event.
- OAuth and agent JWTs use separate authority discriminators. OAuth tokens carrying the agent-only `identity_generation` signal fail closed, including same-ID namespace collision.
- Agent JWTs carry signed tenant and identity generation and are checked against live identity status, owner, tenant, and generation on every verification. Revoked/suspended tokens fail immediately and remain dead after reactivation.
- Delegation tokens, scoped bearer tokens, and agent credentials reject cross-tenant replay and mismatched live identity authority.
- Agent credential issuance and rotation attenuate requested and inherited scopes to the typed issuer authority; wildcard and unrelated-scope amplification fail before credential state changes.
- Protected-write idempotency resolves authentication against the requested tenant before reservation, excludes missing/invalid principals from caching, and namespaces entries by a deterministic digest of the full non-secret authorization context.
- Identity, SCIM, delegation-chain, revocation, and vault operations enforce persisted owner/tenant authorization and validate access attribution.
- Legacy identity quarantine has explicit list/assign endpoints, authorized owner/admin assignment, append-only durable evidence, readiness blocking, and restart-safe authority generation.
- Rate-limit, timeout, readiness, startup contract, package dependency, and SQLite one-worker/one-replica containment paths have behavioral checks.
- Runtime dependencies were updated and both declared requirements sets have no known vulnerabilities in the local strict audit.
